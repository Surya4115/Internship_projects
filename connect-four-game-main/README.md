# 🎮 Connect Four Game

## 📌 Project Overview

Connect Four is a two-player strategy game developed using **HTML5, CSS3, and JavaScript**. The game features a responsive interface, smooth gameplay, and automatic winner detection.

---

## ✨ Features

- 🔴 Two Player Mode
- 🟡 Alternate Turns
- 🏆 Horizontal Win Detection
- 🏆 Vertical Win Detection
- 🏆 Diagonal Win Detection
- 🎨 Responsive UI
- 🔄 Restart Game
- ⚡ Smooth Animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## 📂 Project Structure

```text
connect-four-game/

```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open **index.html** in your browser.
